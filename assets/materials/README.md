# Specimen photographs and documentation

Specimen photo: `<id>.jpg`, square, at least 1600 px, real photograph of the project's own material on a dark neutral ground, same angle and lighting for all. Then set `photo: true` on that material in `js/data.js`.

Documentation (real recorded observations only): add files such as `004-before.jpg`, `004-during.mp4`, `004-after.jpg`, then list them in that material's `media` in `js/data.js`.

Ids: 001 Sponge, 002 Ice, 003 Aluminium Foil, 004 Orange, 006 Tomato, 007 Pear, 008 Shaving Foam, 009 Cream, 012 Rose, 013 Cabbage Leaf, 014 Madeleine.
